# 📨 Панель рассылок Telegram

Бот-панель для рассылок через **личные аккаунты Telegram** (не через бота).
Подключаешь аккаунты, создаёшь посты с Markdown и фото, привязываешь аккаунты
к чатам со своими ссылками и интервалами.

## Возможности

- 👤 **Аккаунты** — подключение через номер (код + пароль 2FA). Каждый аккаунт
  можно **выключить** (перестаёт отправлять) или удалить. 🔴/🟢 статус.
- 📣 **Посты** — текст с **Markdown** (`**жирный**`, `__курсив__`, `~~зачёркнутый~~`,
  `` `код` ``, `[текст](ссылка)`, ` ```блок``` `) + **фото**. Превью в панели
  совпадает с тем, что уйдёт в чат. Плейсхолдер `{link}` подставит ссылку аккаунта.
- 📨 **Рассылки** — мастер связывает пост + несколько аккаунтов + чаты.
  Для **каждого аккаунта** своя ссылка, свой чат и свой интервал.
- ⏱ **Интервалы** — готовые пресеты (5 мин … 24 ч) или свой عدد минут.
  Отправка идёт фоном, пауза/запуск одной кнопкой.
- 🎨 **Цветные кнопки** Bot API 10.x: зелёные (`success`), красные (`danger`),
  синие (`primary`) — управление интуитивное.

## Стек (актуальные версии)

| Зачем | Библиотека |
|---|---|
| Панель-бот, цветные кнопки, FSM | `aiogram 3.31` (Bot API 10.3) |

## Установка

1. **Ключи API** — возьми `API_ID` и `API_HASH` на <https://my.telegram.org>
   (раздел «API development tools»).
2. **Токен панели** — создай бота у [@BotFather](https://t.me/BotFather), забери токен.
3. **Свой ID** — узнай у [@userinfobot](https://t.me/userinfobot).

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Linux/macOS
pip install -r requirements.txt
copy .env.example .env        # и заполни: BOT_TOKEN, ADMIN_IDS, API_ID, API_HASH
python run.py
```

Открой своего бота, нажми `/start`.

### Прокси (если Telegram недоступен напрямую)

Если `api.telegram.org` не пингуется (частый случай на хостингах и в РФ),
добавь в `.env` строку с прокси — и бот, и аккаунты пойдут через него:

```env
PROXY=socks5://127.0.0.1:1080
# или с логином: socks5://user:pass@host:port
# или HTTP:     http://127.0.0.1:8080
```

Без прокси соединение с Telegram просто не установится — проверить доступ
можно так: `curl -I https://api.telegram.org`.

## Структура

```
run.py                  точка входа: бот + планировщик
app/
  config.py             .env, пути, валидация
  database.py           модели: Account, Post, Task
  bot.py                Bot/Dispatcher, run_task, scheduler_loop
  keyboards.py          клавиатуры (цветные кнопки)
  tgsend/manager.py     пул Telethon-клиентов, Markdown→HTML
  handlers/
    start.py            меню, помощь
    accounts.py         аккаунты: логин, вкл/выкл, удаление
    posts.py            посты: создание, превью, правка
    tasks.py            рассылки: мастер создания, управление
data/                   сессии аккаунтов, фото, bot.db (создаётся сама)
```

## Как это работает

- Аккаунты хранят MTProto-сессии в `data/sessions/` — после запуска клиенты
  переиспользуются, переключение между аккаунтами без переподключений.
- Планировщик каждые 30 секунд ищет рассылки с истёкшим интервалом и шлёт их
  до 5 одновременно. Markdown уходит нативным `parse_mode='md'`.
- **Флуд-паузы** обходятся мягко: до 60 с Telethon ждёт сам, длиннее —
  рассылка уходит в кулдаун и отправляется после паузы (не считается ошибкой).
- **Масштабирование**: под нагрузкой (десятки аккаунтов) в пуле держится не
  больше 10 подключений, лишние отключаются по LRU и поднимаются заново при
  необходимости.

## ⚠️ Важно

Используй аккаунты, которыми владеешь, и отправляй в чаты, куда тебя добавили.
Telegram ограничивает активность автоматизированных аккаунтов — соблюдай
разумные интервалы (от 5–15 минут), иначе аккаунт может получить флуд-бан.
